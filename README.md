# Static Excel Store — نسخة أولية

- افتح catalog.xlsx وعدّل المنتجات والتصنيفات والإعدادات دون تغيير رؤوس الأعمدة.
- الصور: روابط HTTPS أو ملفات داخل src/assets، افصل الروابط بـ |. المعرفات ثابتة وفريدة بالإنجليزية.
- على Windows: ثبّت Python 3 ثم شغّل build.bat. أو `python -m pip install -r requirements.txt` ثم `python build.py`.
- مجلد dist هو المخرجات الثابتة. افتح dist/index.html أو شغّل `python -m http.server 8000 --directory dist`.
- Cloudflare Pages: ارفع المصدر لمستودع GitHub مستقل، اختره في Cloudflare Pages، أمر البناء `pip install -r requirements.txt && python build.py` ومجلد المخرجات `dist`. لا تستخدم GitHub Pages للتجارة الفعلية.
- قبل التشغيل التجاري: غيّر بيانات المنتجات التجريبية، املأ base_url وwhatsapp أو telegram، عدّل نصوص السياسات في build.py وفق النشاط والقانون، ثم غيّر demo إلى 0. النسخة التجريبية تمنع إرسال الطلبات والفهرسة.
- WhatsApp يفتح رسالة جاهزة، Telegram ينسخها ثم يفتح المحادثة؛ العميل يضغط إرسال. لا تأكيد تلقائي ولا تحصيل ولا قاعدة طلبات.
- السلة محلية للمتصفح؛ لا Google Login ولا مزامنة متعددة الأجهزة، ولا قياس زيارات عالمي. المخزون يدوي. الصور المبدئية رسوم تجريبية وليست صور منتجات حقيقية.
- لا ترفع أسراراً أو بيانات عملاء إلى GitHub. إجمالي الطلب تقديري ويؤكد المتجر السعر والمخزون والشحن.
