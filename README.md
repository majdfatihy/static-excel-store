# Static Excel Store

- افتح catalog.xlsx وعدّل المنتجات والتصنيفات والإعدادات دون تغيير رؤوس الأعمدة.
- الصور: روابط HTTPS أو ملفات داخل src/assets، افصل الروابط بعلامة |. المعرفات ثابتة وفريدة بالإنجليزية.
- في Settings: shipping تكلفة الشحن الافتراضية، وshipping_by_governorate اختياري بصيغة القاهرة=50|الجيزة=60. القيم مثال للتوضيح فقط. payment_methods يحدد الخيارات مفصولة بعلامة |. whatsapp رقم دولي دون +، وtelegram اسم المستخدم دون @.
- على Windows: ثبّت Python 3 ثم شغّل build.bat. أو python -m pip install -r requirements.txt ثم python build.py --publish-root. هذا يجدد dist وملفات النشر في جذر المستودع. ارفع الملفات المتغيرة، بما فيها المحذوفة، إلى main.
- للمعاينة محلياً: python -m http.server 8000 --directory dist.
- demo=1 يحمي المعاينة من الفهرسة ويجعل الرسائل استفسارات غير مؤكدة. قبل التشغيل التجاري على استضافة تسمح بالتجارة: عيّن بيانات المنتجات والأسعار والصور الحقيقية وعنوان الموقع وراجع السياسات ثم غيّر demo إلى 0.
- WhatsApp ينسق تفاصيل كل منتج (سعر الوحدة والكمية والإجمالي)، وملخص الحساب والشحن وبيانات العميل في رسالة منظمة. WhatsApp وTelegram يفتحان رسالة معدة للإرسال؛ لا يرسل الموقع الرسائل بنفسه ولا يحصّل الدفع. طرق الدفع خيارات في الطلب فقط.
- السلة محلية للمتصفح؛ لا تسجيل دخول أو مزامنة بين الأجهزة. لا ترفع أسراراً أو بيانات عملاء إلى GitHub. الأسعار والمخزون والشحن تخضع للتأكيد.
- GitHub Pages للمعاينة وليس للبيع التجاري. Cloudflare Pages: أمر البناء pip install -r requirements.txt && python build.py، ومجلد المخرجات dist.

- افتح نسخة المعاينة المنشورة: https://dev.majdfatihy.com/static-excel-store/ .

## Language and checkout

- السلة الجانبية تتضمن نموذج الطلب الكامل، وتفتح واتساب أو تيليجرام في تبويب جديد. لا يتم إرسال الرسالة قبل تأكيد العميل داخل تطبيق التواصل.
- لغة المتصفح والمظهر النظامي يُستخدمان تلقائياً ما لم يختر العميل إعداداً يدوياً؛ تحفظ التفضيلات في LocalStorage.
- يمكنك إضافة الأعمدة الاختيارية name_en وdescription_en وkeywords_en وseo_title_en وseo_description_en إلى Products، وname_en إلى Categories. في Settings يمكن إضافة name_en وheadline_en وdescription_en وpayment_methods_en (بنفس ترتيب طرق الدفع العربية). إذا لم توفر ترجمة لمنتج جديد يظهر نصه الأصلي. الروابط الأساسية وبيانات SEO الثابتة تبقى عربية؛ لا توجد صفحات إنجليزية مستقلة.

- إصدار المعاينة الحالي: تحسين السلة الجانبية وتفضيلات اللغة والمظهر.

- اختيار المحافظة من خانة بحث وقائمة واحدة. المنتجات المقترحة تُولد في HTML تلقائياً؛ يمكن تحديد عددها بإضافة recommendation_limit في Settings (الافتراضي 5، الحد الأقصى 10).
